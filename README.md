## 🚀 Projets

### 🗓️ CRM de gestion RH (projet interne, Epie Formation)
> Application web pour gérer congés, absences et annuaire du personnel, sans abonnement.

- **Besoin :** les demandes de congé se faisaient sur papier, sans suivi fiable.
- **Réalisation :** application Python (Flask, SQLite), trois niveaux d'accès (direction, RH, employé), calcul des jours ouvrés et fériés, import et export Excel, journal d'audit, sauvegardes automatiques.
- **Note :** construit avec l'aide de l'IA. Le dépôt contient uniquement des **données fictives**, avec l'accord de l'entreprise.
- 🔗 [Voir le dépôt](https://github.com/Ckebdi/epie-crm)

---

### 🔄 Automatisation du suivi d'assiduité (SoWeSign)
> Scripts Python connectés à l'API d'une plateforme d'émargement.

- **Réalisation :** scripts Python branchés sur l'API SoWeSign (validés d'abord sur un environnement de test fourni par l'éditeur), données centralisées dans une base Airtable de 4 tables, avec dédoublonnage et normalisation.
- **Impact :** environ **8 heures gagnées par semaine** pour l'équipe.
- *Code non publié (données internes).*
